配置与使用说明

在线表示平台连接可用。点击账号卡片设置凭据、固定回复和客户端授权；点击「消息」查看是否收到消息并手动回复。默认仅接收，不自动回复。

需要执行任务时，在浏览器扩展「插件管理 → 平台消息 → 配置」添加流程或对话规则。客户端需获授权并保持在线；回复平台需由流程或插件调用发送消息能力。

导出包含已保存的账号参数和凭据，不含消息历史。导入按 ID 合并，同 ID 更新，其他账号保留；启用状态与固定回复随配置恢复，仅保留当前服务器有效的客户端授权。导出文件含明文凭据，请妥善保管。

    研发工具

    配置与使用说明

    「连接类型」包括数据库、项目协作、构建、代码仓库、远程服务器和对象存储，均为可选，支持多个连接。S3 为对象存储，支持 Amazon S3、MinIO 等兼容服务。

    「连接名称」用于区分连接；「操作超时」单位为毫秒，默认 30000，可设为 1000–120000。连接供 MCP、助手、脚本和流程共用。

    保存只检查配置格式，不连接远端，下次调用生效。服务地址以 MCP Server 所在机器为准，包含实际部署路径；容器内的 127.0.0.1 指向容器本身。

    填写连接参数后可点击「测试连接」，无需先保存或启用；编辑时密码留空沿用已保存的凭据。测试使用当前表单配置，不保存修改，也不修改远端业务数据。

    数据库测试执行 SELECT 1，Redis 使用 PING，Jira、Confluence、Jenkins 和 GitLab 验证登录身份，S3 检查桶访问权限，SSH 验证登录与主机指纹。测试通过不代表已拥有全部查询、写入或命令权限。

    「启用连接」控制是否允许调用此连接；操作授权按工具区分：数据库等允许写入，S3 允许上传或删除对象，Jenkins 允许触发构建，GitLab 允许写入或触发流水线，SSH 允许执行命令。

    密码、令牌和私钥保存在服务端，编辑时留空保留已有值。持有 HTTP 令牌的 MCP 客户端可直接使用；浏览器助手、脚本和流程需开启对应客户端的授权，并在「插件管理」启用对应工具。

    导出包含已保存的连接参数及密码、令牌和私钥。导入按 ID 合并，同 ID 更新，其他连接保留；启用状态与操作权限随配置恢复，仅保留当前服务器有效的客户端授权。导出文件含明文凭据，请妥善保管。

    connectionId 是浏览器配对的 MCP 连接 ID；profileId 是此处显示的研发工具连接 ID，使用 connections 能力取得。写操作需要开启允许写入，结果未知时先核对远端状态。SSH 使用密码或私钥及服务器主机密钥指纹，不提供交互式终端。

    连接与调用示例

    GET /devtools
OPTIONS /devtools/jira/search
POST /devtools/jira/search
{"profileId":"此处的连接 ID","jql":"project = DEMO ORDER BY updated DESC","maxResults":20}

POST /devtools/postgres/query
{"profileId":"此处的连接 ID","sql":"SELECT id, title FROM public.tickets WHERE status = $1 LIMIT 20","params":["open"]}

    PostgreSQL 和 MySQL 每次执行一条 SQL，参数占位符分别为 $1、$2 和 ?。query 使用只读事务，execute 需要允许写入；可访问的表和操作还受数据库账号权限约束。

    以上为 MCP 工具参数中的资源路径，示例表名和字段需换成自己的业务表。

    连接配置

    配置 HTTP MCP 客户端接入、浏览器扩展配对与访问授权。

    配置与使用说明
    连接与权限说明

    HTTP MCP 接入：展开「客户端配置」，复制示例并将占位符替换为当前 HTTP 令牌，添加到支持 Streamable HTTP 的 MCP 客户端；远程访问时将地址改为客户端可访问的服务地址。

    服务端能力：HTTP 令牌代表服务端操作者，可管理账号，访问服务端文件、命令和系统支持的桌面能力。无需扩展在线。

    浏览器操作：扩展通过 WebSocket 配对并开启连接。外部客户端先 GET /clients，选择目标后通过 POST /clients/{clientId}/arp 调用。URL 可追加 ?mcpClientId=目标ID 固定目标；/local 始终指向服务端。

    扩展授权：扩展使用服务端文件和命令前，在扩展「权限」中授权目录；桌面操作单独开启。多个扩展可共享一个账号，普通与隐身环境分别授权。

    配对与重连：填写扩展可访问的 WebSocket 地址，点击「一键配对」生成配对码，再到扩展「MCP 服务器连接 → 一键配对」粘贴并配对。配对码有效期 5 分钟，只能使用一次。扩展连接开关控制重连；网络故障最多重试 20 次，凭据失效时需重新配对。连接或请求中断后不自动重放操作。

    状态与凭据：继续使用同一 --state-dir 保留身份和账号；--password 重置配对密码并撤销旧配对。HTTP 令牌可在本页重置；环境变量指定的令牌需修改部署配置。页面登录状态在当前标签页内保留，刷新后自动恢复；退出或凭据失效时清除。

    启动设置：Node ≥22.16.0，WebSocket 默认 9999、HTTP 默认 9998；--ws-port / --http-port 修改端口，--server-name 设置名称。文件与命令工作目录为启动目录，默认状态目录为 ./data。Bash 按服务端进程权限执行。

    消息处理说明
    仅接收：保存收到的消息，不自动回复；可在「消息」中手动回复，或交给外部程序处理。
    固定回复：由服务端回复新收到的消息，无需浏览器在线；历史消息不补发，发送结果在「消息」中查看。邮件不支持固定回复。
    流程／对话：在已授权客户端「插件管理 → 平台消息 → 配置」添加触发规则，并保持客户端在线。规则与固定回复可同时生效；平台回复需由流程或插件调用发送消息能力。
    
            
    
            
    
          
    
          
    
            
    使用授权说明
    服务端始终可用。可同时授权多个扩展客户端，授权后可配置账号、收发消息；离线客户端上线后生效。
