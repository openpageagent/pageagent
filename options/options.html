Page Agent

页面配置

点击卡片编辑网页地址、匹配规则和页面行为，修改后点击「保存」。内置页面需复制为用户页面后编辑。

页面配置说明

页面匹配：URL 的域名自动纳入匹配；额外域名每行一个，「URL 包含」区分同域名页面。

网络捕获：供「获取请求返回数据」节点使用，修改开关后需刷新目标页面。

自动关闭：流程成功后仅关闭本次新开的标签页，保留复用标签页。

会话保活：在已打开且未被浏览器丢弃的匹配页面中定时请求，携带 Cookie，不刷新页面。请用无业务副作用的查询接口；能否延长会话取决于服务端。

保活参数：URL 可用相对路径，间隔单位为分钟；请求头支持 JSON 或每行 Key: Value，请求体仅用于 POST。状态码用逗号分隔，支持 200-299,304 等范围。

流程配置

将节点编排为顺序执行的流程。点击卡片编辑，节点输出可供后续节点引用；内置流程需复制为用户流程后修改。

流程配置说明

输入输出：说明用途、前置页面状态和数据结构；入参示例仅预填 JSON，不生成表单或强制校验。

标签策略：决定运行时使用的标签页，流程组步骤可覆盖。

数据集：填写 JSON 数组，每项运行一遍；用 {{data.字段}} 引用当前数据。

编辑与保存：点击节点主体编辑，拖拽图标与标题区域排序；节点和通知修改后，还需「保存流程」。

流程组合

将多个已保存流程编排为业务流程。点击卡片编辑；内置流程组需复制为用户流程组后修改。

流程组合说明

输入输出：说明场景和数据约定；入参示例仅预填 JSON，不生成表单、设置出参路径或强制校验。

执行顺序：第一步接收流程组入参，后续步骤接收上一步输出。

步骤策略：可覆盖标签策略，设置失败后是否继续。点击主体编辑，拖拽标题区域排序；修改后还需「保存流程组」。

定时任务

按固定间隔、每天多个时刻、指定日期或 Cron，自动运行流程、流程组或对话，支持输入参数。

定时任务说明

任务配置：绑定流程、流程组或助手并设置触发方式；修改配置或启停状态后需保存。

输入参数：填写 JSON 对象，流程和流程组会预填示例；对话任务还需填写消息。

指定日期：手动添加或从日历勾选；点击「采用勾选日期」后保存，按已存日期运行。

运行条件：使用浏览器时区，浏览器需保持运行；错过超过 5 分钟的固定时刻不补跑。

URL 触发器

当浏览器打开匹配的页面时，自动执行绑定的流程或流程组。

URL 触发器说明

匹配规则：绑定流程或流程组，URL 支持通配符 *，如 https://*.example.com/*。

启停与结果：关闭「启用」并保存后停止后续触发；运行结果见「流程报告」。

流程报告

集中查看流程与流程组的运行结果、节点统计、失败样本、warn/error 事件和可导出的流程报告。

流程报告说明

报告详情：点击记录查看节点结果、耗时、失败样本和警告／错误；顶部展示汇总统计。

导出：支持单次或批量 JSON、HTML，以及失败样本 CSV。

历史清理：支持单条、按日期或全部清理，保留活动中的记录。

MCP 服务器连接

连接 Page Agent 服务端，让本扩展使用本地能力、发送邮件，并与同一服务端的其他客户端通信。外部 MCP 客户端也可通过 HTTP 访问服务端。

MCP 连接与使用说明

先启动服务端，再按用途选择连接方式：

用途连接方式是否需要插件在线
服务端本地操作外部 Agent 使用 HTTP MCP + HTTP 令牌不需要
浏览器与插件操作外部 Agent 连接 HTTP MCP，再选择目标客户端目标插件已配对并连接
插件本地能力与互调插件使用 WebSocket 配对连接本插件已连接；互调时目标也需在线

1. 启动服务端

运行环境：Node 22.16.0+。填写发布包解压目录，在终端切换到希望使用的工作目录，再运行下方命令。示例使用本机默认端口。

工作目录：上方路径只定位服务端程序；文件操作和 Bash 的起始目录取终端当前目录。认证、审计及状态默认保存在该目录下的 ./data，可用 --state-dir <目录> 指定。

两种凭据：配对密码用于插件首次配对，HTTP 令牌用于外部 MCP 客户端，分别生成。未配置时先复用已保存的凭据，没有才自动生成；自动生成的明文只显示一次，请保存。

显式设置：--password <密码> 设置或重置配对密码，重置会撤销已有配对；PAGE_AGENT_HTTP_BEARER_TOKEN 设置 HTTP 令牌。重启时继续使用同一数据目录才能保留身份和凭据。

名称与端口：服务端名称默认取 hostname，可用 --server-name "开发机" 设置；WebSocket 默认 9999，HTTP 默认 9998，可分别用 --ws-port、--http-port 修改。

2. 插件连接服务端（按需）

  1. 新增服务端：填写别名和 WebSocket 地址并保存；本机默认 ws://127.0.0.1:9999，远程填写实际的 wss:// 地址。
  2. 首次配对：点击「配对服务端」并输入配对密码，成功后即可操作连接开关。
  3. 开启连接：配对后打开连接开关；关闭开关会断开连接并停止自动重连，配对信息会保留。
  4. 按需授权：插件使用服务端文件、命令能力时，在「权限」中配置目录；桌面操作需开启「允许操作服务端桌面」。仅操作浏览器页面无需授权服务端目录或桌面。

名称与身份：连接别名由本插件保存，服务端名称由服务端设置；连接日志同时显示双方名称和 ID，可点击复制。当前浏览环境的连接共用客户端身份，普通与隐私环境的身份和配对信息独立。

凭据恢复：密钥丢失或凭据失效时，连接开关保持不变，点击「重新配对」更新密钥。开关开着就自动连接，关着就保持断开；更换服务端会重置目录和桌面授权。

连接重试：网络故障最多自动重试 20 次；凭据缺失或明确失效时停止尝试，等待重新配对。

标签策略：未指定 tabId 时，「复用已打开标签」取当前页，「固定当前标签」首次请求时绑定，「固定打开标签」按当前 HTTP(S) 地址新建并固定。显式 tabId 优先；流程使用自身策略。

3. 外部 Agent 连接 HTTP MCP（按需）

接入方式：在 Codex、Claude Code 或其他 MCP 客户端中配置 Streamable HTTP，服务端保持运行即可。只使用服务端本地能力时可跳过插件配对；操作页面时再连接目标插件。不支持 stdio。

连接配置：将 <HTTP令牌> 替换为启动时显示或自行设置的 HTTP 令牌；保留 Bearer 前缀。远程连接使用实际 HTTPS 地址和端口，HTTP 地址不能由 WebSocket 地址直接推算。

按客户端要求填写对应字段，此处只生成可复制的示例。默认 URL 不绑定插件，可直接使用本地能力，也可选择不同客户端。

固定目标（可选）：URL 可追加 ?mcpClientId=<目标客户端ID>，之后可直接访问该插件的 /page/current 等资源；同一会话不能更换目标。/local 始终指向当前服务端。

4. 使用本地能力与调用客户端

外部 MCP 提供 GET / POST / PUT / PATCH / DELETE / OPTIONS 六个方法工具。下面的路径是工具的 ARP 参数，都经 /mcp 调用。

  1. 发现服务端能力：OPTIONS / 查看目录；GET /local 获取本地能力和工作目录。用 GET /local/environment 查询环境，或 POST /local/read 读取文件，body 示例为 {"path":"README.md","limit":20}。
  2. 选择目标插件：GET /clients 查看名称、ID 和连接状态，选择已就绪的客户端。
  3. 调用目标插件：POST /clients/{clientId}/arp，body 为 {"method":"GET","request":{"uri":"/page/current"}}。将内层方法改为 OPTIONS、URI 改为 / 可发现插件能力；响应链接仍需通过同一客户端转发。

插件之间通信：扩展内 Agent 先 GET /connections 选择服务端连接，再沿 clients 链接查询全部客户端及总数（含自己），通过 POST /connections/{connectionId}/clients/{clientId}/arp 调用其他客户端。connectionId 是本插件保存的服务端连接 ID，clientId 是目标客户端 ID。查询需 connections.read，调用需 connections.execute；服务端拒绝自己调用自己，原因为 SELF_CALL_FORBIDDEN。

5. 权限与执行范围

HTTP 本地能力：HTTP 令牌代表服务端操作者，文件操作以服务端启动工作目录为根，可用平台支持的桌面能力，不依赖插件的目录或桌面授权。

插件本地能力：扩展内 GET /local 返回已授权连接和目录，使用返回的完整链接调用。新目录先保存、确认路径，再授权；修改路径会清除权限，父目录授权覆盖子目录。

命令与桌面：Bash 按服务端进程权限执行，工作目录不是命令沙箱。桌面操作作用于服务端登录桌面，受系统权限限制；Linux 不支持桌面操作。

客户端转发：可读取资源、操作页面／浏览器及使用目标插件在当前服务端已授权的本地能力。流程、脚本、对话、定时任务和应用动作的创建与运行由扩展内管理；转发请求不能再调用其他客户端。

断线或取消：不自动重放请求；结果未知时先核对实际效果，再决定是否重新提交。

自动同步

自动同步仅在容器版本中启用，且需指定同步参数。

同步说明

启动同步：下次启动时加载指定的可同步版本，未指定则跳过。

同步条件：运行设置允许、连接就绪且版本兼容；容器指定的目标同步完成前暂缓任务执行。

邮件服务器连接

配置 SMTP 发件账户，通过支持邮件发送的 MCP Server 发送测试邮件、流程结束通知和邮件节点消息。

邮件连接与使用说明
  1. 选择服务端：MCP 配对并连接后，在 SMTP 卡片选择支持邮件发送的服务端。
  2. 填写账户：按服务商要求填写 SMTP、认证及发件邮箱；TLS 通常用 465，STARTTLS 用 587。
  3. 保存与测试：测试使用当前配置发送真实邮件，不会自动保存；修改后仍需点击「保存」。

流程通知：在流程编辑页设置成功／失败通知，或添加邮件节点；共用已保存账户与服务端。

通知总开关：默认开启，切换立即保存；关闭后停止后续发送及测试。

账户存储：配置保存在扩展中，发送时交给 MCP Server，服务端不保存账户。

模型配置

管理流程、脚本和对话使用的模型服务，配置默认服务及全局上下文设置。

模型连接与使用说明

默认服务：用于未指定服务的调用，助手可另选；脚本通过 api.model.chat() 调用。

新增与保存：新增先编辑，保存后创建服务；「保存并测试」只保存当前服务，全局上下文需点击「保存」。复制服务不复制密钥。

协议与地址：选择服务支持的协议，填版本根地址或完整接口地址，系统自动补全接口路径。

密钥：不回显，留空保留原值，点击「清除密钥」移除。User-Agent 仅用于当前服务，留空用浏览器默认值。

视觉与摘要：留空使用文本模型；截图需支持图片输入，摘要共用服务地址和凭据。思考级别 auto 不传参数。

请求重试：0–50 次，默认 15，0 为关闭；仅重试瞬时故障，配额和账单错误不重试。

全局上下文：对所有服务生效，1 K = 1000 Token；压缩阈值为 50–90%，90% 使用默认阈值。

版本操作

客户端设置说明

共用身份：当前浏览环境的所有 MCP 连接共用名称和 ID；改名不改变身份。

重置身份：清除本环境所有连接凭据，需全部重新配对；服务端旧配对需另行撤销。

配对说明

配对凭据：验证成功后保存凭据，密码用后清除。配对保持开关原状态；连接关闭时，配对只临时联系服务端，完成后立即断开。

重新配对：更新密钥，不改变连接开关。开关开启时自动使用新密钥连接，关闭时保持断开。

更换服务端：保留连接开关和目录配置；工作目录恢复只读，其他目录及桌面权限关闭，需重新授权。

目录权限

目录权限说明

编辑保存：点击目录卡片编辑，保存后生效；工作目录默认可读。

目录授权：新目录先保存并确认路径，再授权；修改路径会关闭全部权限。

权限边界：命令使用服务端进程权限，不受文件开关限制；父目录授权可能覆盖子目录，关闭子目录权限不构成系统级拒绝。
